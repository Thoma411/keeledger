# Keeledger

一个零知识加密的账号密码管理器/密码本，基于 Flutter 构建，现已适配 **Windows / macOS / Android**。

## 功能特性

- 🔐 **零知识信封加密**：主密码不离开本地，敏感字段以 AES-256-GCM 加密存储
- 💾 **本地 SQLite 存储**：数据完全保存在本地，无云端依赖
- ☁️ **WebDAV 云同步**：支持以加密形式备份至支持 WebDAV 的网盘（目前仅适配了坚果云）
- 📥 **CSV 数据迁移**：支持批量导入导出
- 🔍 **多关键词搜索**：支持 Ctrl+F 快速查找与拼音字母索引

## 快速上手

1. 首次打开应用，点击 **"创建新数据库"** 并设置主密码；
2. **务必妥善保存应用生成的"恢复密钥"** —— 这是忘记主密码后找回数据的唯一凭证；
3. 添加账户条目即可开始使用（平台名称不可重复）。
